# CLAUDE.md

## Project facts
Shared with every session and agent. Update these when they change and tell the user.
- Stack: Python 3.12/3.13 web app in `subzero_ai/` (version 0.11.0). The website is Code plus the admin Settings page, with the mentors' Review, read-only chat page, Needs a mentor and Files pages; chat happens in Slack DMs with mentor approval. Projects, artifacts/explainers, share links, uploads and web chat were removed in 0.11. Starlette + Uvicorn, Jinja2 templates (`subzero_ai/templates/`), plain JS/CSS (`subzero_ai/static/`), SQLite (`subzero_ai/db.py`, append-only `MIGRATIONS` list keyed by `PRAGMA user_version`). On the Python side, hand-written HTTP clients and no vendor SDKs: Claude Messages API in `subzero_ai/claude.py`, Slack Web API in `subzero_ai/slack_api.py`, Slack Socket Mode over `websockets` in `subzero_ai/socket_mode.py`. A Node.js 22 Pi gateway in `pi_gateway/` (used when `AI_BACKEND=pi`) talks to the app over stdin JSONL through `subzero_ai/pi_client.py`, using `@earendil-works/pi-ai`; the optional Claude subscription bridge uses the Claude Agent SDK. `AI_BACKEND` is `anthropic` (default), `pi` or `fake`. Runs as a Windows service (WinSW, embedded Python) on a mini PC behind a Cloudflare Tunnel to `http://127.0.0.1:8787`. Code sandboxes (`subzero_ai/sandbox.py`, Hyper-V VMs) reach the internet only through the egress proxy in `subzero_ai/egress_proxy.py`, which listens on the sandbox switch address (`sandbox_host_address`, 10.77.0.1) only and checks a per-sandbox token; it starts only when `CODE_SANDBOX=hyperv`. The new Code engine (`subzero_ai/code_engine.py`, default `CODE_ENGINE=agent`; `classic` is the switch back) runs the Claude Agent SDK inside the sandbox through `sandbox_runner/` (Node 22, JSON lines); the sandbox never holds a real key, because its requests go to `subzero_ai/anthropic_gateway.py` on the sandbox host address, port 3129, which checks the per-sandbox token, adds the key or the testing-only subscription token, enforces models, safety rules, web tools and the cost cap. `subzero_ai/archive.py` archives and deletes old website chats; `subzero_ai/files_admin.py` and `web_files.py` are the Files page; `sandbox_image.py` and `sandbox_provision.sh` bake the tools into the base disk (`prepare-sandbox-image.cmd`).
- Build: `python packaging/build_windows.py` makes the Windows release zip (every download pinned by SHA-256, Python wheels from `requirements-lock.txt`, Node.js and the gateway's npm packages via `npm ci`, `sandbox_runner/` as source plus its lock file (its packages are installed in the sandbox base disk by `prepare-sandbox-image.cmd`); the build host needs Node/npm and the zip is about 255 MB). GitHub Actions minutes are used up, so don't rely on CI; build and test locally.
- Test: `pip install -r requirements-dev.txt`, then `python -m unittest discover -s tests -t .` (1535 tests, about 2-3 minutes), plus `cd pi_gateway && node --test` (46 tests) and `cd sandbox_runner && node --test` (23 tests); both need Node 22 and `npm ci` in their folder. Tests use `FakeClaude` (`subzero_ai/claude.py`) and fake Slack clients from `tests/helpers.py`, and a fake gateway (`tests/fake_pi_gateway.py`) for the Pi backend and a fake runner (`tests/fake_agent_runner.py`) for the Code engine; no network or keys needed.
- Lint/format: none configured. Match the surrounding style (type hints, `from __future__ import annotations`, 120-column lines, short docstrings).
- Conventions: every AI call goes through one client object with `stream()` and `complete()` (built in `build_services`, `subzero_ai/web.py`). Settings are a dataclass in `subzero_ai/config.py` (from `config.env`), overridable from the admin page via `subzero_ai/saved_settings.py`. Important actions are written with `db.audit(...)`. User-facing text is plain language for high-school students. `docs/DESIGN.md` is the visual standard. `FAKE_CLAUDE=1` gives canned replies, with magic words (ALERT-TEST, ERROR-TEST, SCREEN-FLAG, SCREEN-ERROR) for testing.
- Off-limits: don't weaken the mentor approval flow (approval window, screener, MENTOR ALERT, rejections) without the user's say-so. Keep the team's name and number off the site; say "the team". Never call the feature "Claude Code" on the site or in messages (it is "Code"). Never put API keys or tokens in code, tests, commits, or chat. Users install from `SubZeroAI-windows.zip`, never GitHub's source zip.
