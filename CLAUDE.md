# CLAUDE.md

## Project facts
Shared with every session and agent. Update these when they change and tell the user.
- Stack: Python 3.12/3.13 web app in `subzero_ai/`: Starlette + Uvicorn, Jinja2 templates (`subzero_ai/templates/`), plain JS/CSS (`subzero_ai/static/`), SQLite (`subzero_ai/db.py`, append-only `MIGRATIONS` list keyed by `PRAGMA user_version`). On the Python side, hand-written HTTP clients and no vendor SDKs: Claude Messages API in `subzero_ai/claude.py`, Slack Web API in `subzero_ai/slack_api.py`, Slack Socket Mode over `websockets` in `subzero_ai/socket_mode.py`. A Node.js 22 Pi gateway in `pi_gateway/` (used when `AI_BACKEND=pi`) talks to the app over stdin JSONL through `subzero_ai/pi_client.py`, using `@earendil-works/pi-ai`; the optional Claude subscription bridge uses the Claude Agent SDK. `AI_BACKEND` is `anthropic` (default), `pi` or `fake`. Runs as a Windows service (WinSW, embedded Python) on a mini PC behind a Cloudflare Tunnel to `http://127.0.0.1:8787`.
- Build: `python packaging/build_windows.py` makes the Windows release zip (every download pinned by SHA-256, Python wheels from `requirements-lock.txt`, Node.js and the gateway's npm packages via `npm ci`; the build host needs Node/npm and the zip is about 255 MB). GitHub Actions minutes are used up, so don't rely on CI; build and test locally.
- Test: `pip install -r requirements-dev.txt`, then `python -m unittest discover -s tests -t .` (620 tests, about 1.5 minutes), plus `cd pi_gateway && node --test` (46 tests, needs Node 22). Tests use `FakeClaude` (`subzero_ai/claude.py`) and fake Slack clients from `tests/helpers.py`, and a fake gateway (`tests/fake_pi_gateway.py`) for the Pi backend; no network or keys needed.
- Lint/format: none configured. Match the surrounding style (type hints, `from __future__ import annotations`, 120-column lines, short docstrings).
- Conventions: every AI call goes through one client object with `stream()` and `complete()` (built in `build_services`, `subzero_ai/web.py`). Settings are a dataclass in `subzero_ai/config.py` (from `config.env`), overridable from the admin page via `subzero_ai/saved_settings.py`. Important actions are written with `db.audit(...)`. User-facing text is plain language for high-school students. `docs/DESIGN.md` is the visual standard. `FAKE_CLAUDE=1` gives canned replies, with magic words (ALERT-TEST, ERROR-TEST, SCREEN-FLAG, SCREEN-ERROR) for testing.
- Off-limits: don't weaken the mentor approval flow (approval window, screener, MENTOR ALERT, rejections) without the user's say-so. Keep the team's name and number off the site; say "the team". Never put API keys or tokens in code, tests, commits, or chat. Users install from `SubZeroAI-windows.zip`, never GitHub's source zip.
