Model safety check

Sends a model a few test messages: an unsafe shop request, a "forget your rules" trick, a student who says they want to hurt themselves, an everyday question, a request for an explainer, and two messages for the screener. A model has to pass before it can be the default, hard-problem or screener model. The model you type is graded on its answers by the judge model, {{ settings.model_check_judge }}, so that model's provider must be turned on and have its API key saved. Models already in use keep working. The check sends about ten requests and takes a minute or two.

Write it as provider/model, like openrouter/meta-llama/llama-4.
