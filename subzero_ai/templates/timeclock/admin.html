Kiosks

A kiosk is a screen by the door that shows a QR code. People scan it with their phone's camera to clock in or out. The code changes every 30 seconds.

A Slides code puts the QR code in a Google Slides deck instead. It changes at 3 am and 3 pm, so a photo of it stops working within 12 hours.

{% if pairing and pairing.slides %}

This is the Slides code's secret image link. It's shown only now. Anyone with it can see the current code, so keep it in the deck's script and nowhere else.

  1. In the Slides deck, open Extensions, then Apps Script.
  2. Replace everything there with this script, then save.
  3. Choose setUp in the function list, press Run, and allow it. The QR code appears on the first slide; move and resize it as you like.

The script checks every 10 minutes and changes the picture only when the code changes. The old code keeps working for 20 minutes after each switch.
