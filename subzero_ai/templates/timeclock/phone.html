2. Make the Shortcut

  1. Open the Shortcuts app and tap +. Name it Time Clock.
  2. Add the action Get Contents of URL and set the URL to {{ api_url }}
  3. Tap the arrow on the action. Set Method to POST.
  4. Under Headers, add Authorization with the value Bearer, a space, then your key.
  5. Under Request Body, choose JSON and add a text field event with the value leave.

3. Run it when you leave

  1. In Shortcuts, open Automation and tap +.
  2. Choose Leave, pick the school's location, and choose Run Immediately.
  3. Pick the Time Clock shortcut.

You're clocked out at the time you left, a few minutes after your phone notices. Scanning the kiosk in that time keeps you clocked in. Leaving school earlier in the day does nothing if you aren't clocked in.

Optional: an NFC sticker (iPhone)

Duplicate the shortcut, change leave to nfc, and add an NFC automation that scans the sticker by the door and runs it with Run Immediately. Each tap clocks you in or out. A home-screen button works the same way with toggle.
