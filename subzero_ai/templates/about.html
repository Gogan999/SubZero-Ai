How {{ settings.app_name }} works

Powered by Claude, an AI made by Anthropic. Claude can be wrong, so check anything important with a mentor.

What Code does

Code lets Claude work on the team's robot code. You describe a task, like "the arm overshoots at high speed, find out why and fix it". Claude works on its own copy of the team's repository: it reads the files, makes changes, and can run builds and tests. Nothing is ever pushed to GitHub. You can read every step Claude takes, as it happens.

What a mentor approves

  • A mentor reads every student request before Claude starts. Until then, nothing runs.
  • Your follow-up questions in a session also go to a mentor first.
  • If "Plan first" is ticked, Claude writes a plan and waits. A mentor approves the plan before Claude changes anything.
  • A mentor can decline at any step and say why. You will see their note.
  • Mentors can stop a session at any time.

What the sandbox is

Each session gets its own sandbox: a separate virtual computer that Claude uses and nobody else shares. It can only reach a short list of websites that robot builds need, like the places Gradle downloads from. It is deleted after a while, so don't keep anything there. Claude's work is saved as a patch before the sandbox goes away.

How the results come back

When Claude is done, the changes are saved as a patch, a file that lists exactly which lines were added and removed. A mentor looks at the changes first. When a mentor releases them, you can read them on the session page and download the patch. To use it, apply it in your own copy of the repository with git apply, then test it on the robot before you commit it.

Chatting with Claude

To ask Claude a question that isn't about code in the repository, message the bot in Slack. Who can see what

  • Mentors can read every Slack chat with the bot, including messages that are waiting for review and ones that were rejected. They can also read every Code session.
  • Other students can't read your chats or your Code sessions.
  • Nothing here is a private conversation. Don't share personal information like your address or phone number.
  • What you send, and what Claude does for you, is stored on the team's server. It is also sent over the internet to the company whose AI answers, which is usually Anthropic (Claude). Your name and Slack details are never sent. Mentors can tell you how long that company keeps messages.

Check before you trust it

Claude can be wrong. Read the changes before you use them, and confirm anything safety-critical with a mentor before it goes on the robot. Never use an AI answer as a reason to skip shop safety rules.

If something's wrong

If you're going through something hard, talk to a parent, a mentor, or your school counselor. In the US you can call or text 988 any time, and call 911 in an emergency.
